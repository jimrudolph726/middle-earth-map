# Gandalf the White curated journey

This directory contains the 18 illustrations used by the completed **Gandalf the White: From Zirakzigil to the Black Gate** story.

## Approved opening illustrations

The first three illustrations predate the completed journey and were explicitly retained unchanged:

- `scene-01.png` — Awakening on Zirakzigil
- `scene-02.png` — Gwaihir Bears Him South
- `scene-03.png` — Clothed in White

Their approved SHA-256 hashes are enforced by `tests/map-data.check.cjs`.

## Journey illustrations

`journey-04.webp` through `journey-18.webp` continue the same visual language in a responsive 16:10 format. They were generated as a coordinated set and converted to lossy WebP for the static site.

See `PROVENANCE.md` for the generation disclosure, source roles, prompts, and correction history.
