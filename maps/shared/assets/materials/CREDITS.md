# Shared atlas study materials

This register covers the physical study environment shared by multiple atlas
volumes. The processed asset is self-hosted so the static site has no runtime
dependency on its source provider.

## `atlas-mahogany-v1.webp`

- Source asset: [Dark Wood](https://polyhaven.com/a/dark_wood), 2K diffuse map
- Source description: dark cherry/mahogany hardwood
- Source authors: Dario Barresi (baking), Dimitrios Savva (photography), Rico Cilliers (tiling)
- Provider: Poly Haven
- License: [CC0 1.0 Universal](https://polyhaven.com/license)
- Atlas processing: resized from 2048 × 2048 to 1200 × 1200; contrast increased
  slightly; brightness reduced; saturation softened; encoded as lossy WebP
- Purpose: the stationary mahogany desk beneath the individual volume mounts
- Output size: 167,694 bytes
- SHA-256: `CC7F24F2F5EE5CCB439DDD5602951B0BC7C33823A2CF30A79D7191F5BF33FA64`
- Processed: 2026-08-31

The original multi-megabyte source download is not deployed with the site.
