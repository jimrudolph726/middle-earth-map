# Shire harvest-almanac presentation

- Desk: the existing [shared mahogany material](../../shared/assets/materials/CREDITS.md).
- Wheat-linen mat: reuses the CC0 Poly Haven Rough Linen derivative documented in
  [Beleriand's material register](../../beleriand/assets/materials/CREDITS.md),
  recolored at runtime with CSS and the mat's warm tint layer.
- Copper frame: reuses the existing brass texture documented in
  [Middle-earth's material register](../../middle_earth/assets/materials/CREDITS.md),
  with Shire-specific copper rails and honey highlights.
- `barley-ornament.svg` and the `barley-acorn` frame motif in the shared frame
  module: original code-drawn SVG ornaments created for this atlas, September 2026.
  No externally sourced or AI-generated raster artwork was added for this treatment.

Existing map artwork and lore data are unchanged.
